# CampusNotes

CampusNotes is a simple repository for organizing and maintaining campus-related notes.

## Project Purpose

The project demonstrates basic Git and GitHub collaboration, including repository management, branching, commits, and pull requests.

## Project Files

| File | Description |
|------|-------------|
| notes.txt | Contains campus notes. |
| workflow-test.txt | Demonstrates the Git clone, push, and pull workflow. |

## Getting Started

1. Clone the repository.
2. Open the project folder.
3. Read notes.txt to view the campus notes.
4. Check workflow-test.txt for the Git workflow demonstration.
